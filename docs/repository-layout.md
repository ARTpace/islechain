# 工程目录与提交约定

## 文件层级

| 目录 | 用途 |
| --- | --- |
| `main.py`、`core/` | 服务入口与业务实现；节点、ComfyUI、游戏功能按现有前缀分域 |
| `routers/` | HTTP 接口层，调用 core，不存放用户数据 |
| `static/`、`prompt/` | 页面、样式、浏览器脚本与提示词界面 |
| `templates/` | 游戏运行时、工程及模型查看器模板，属于运行依赖 |
| `workflows/` | 可分享的工作流及配套配置 |
| `tools/` | 开发工具、音频和 3D worker、第三方许可证 |
| `desktop/` | 桌面壳与打包脚本；构建输出和依赖不入库 |
| `tests/` | 自动化测试；固定样例放 fixtures/ |
| `docs/` | 开发设计、运行说明与验证边界；入口为 README.md |
| `data/` | 少量受控默认配置；个人数据、缓存及资源包按忽略规则留在本地 |
| `artifacts/`、`output/`、`scratch/` | 本地报告、截图、生成结果、实验，不入库 |

## 本次整理

保留当前 Python 导入、静态资源和打包路径，避免仅为目录美观移动运行模块。
排除 `.oil-ui/`、`.playwright-cli/` 本机会话；保留实体文件以便追溯。
补齐开发文档的 Git 放行规则，避免主要功能文档只存在于开发机。
音频及 3D worker 的分发文件、模板和第三方许可证是运行所需文件，应随源码提交。

## 提交边界

提交源码、测试、可分享配置、模板、许可证与开发文档。
不提交凭据、用户画布、会话、依赖目录、安装包、输出媒体或本机调试记录。
外部资源包按既有独立资源仓库约定管理。
