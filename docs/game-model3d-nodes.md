# 3D 画布节点

在游戏画布的创建菜单中添加“模型资产”“3D 模型生成”“3D 动画”。三个节点直接展示模型；高级参数在独立弹窗，不在卡片内展开。

也可以把 **GLB、glTF、FBX、OBJ、STL、PLY** 文件直接拖到画布空白处，自动创建模型资产节点。多个模型分别创建节点；普通画布会自动关联模型资产项目，无需先初始化游戏工程。“导入/替换模型”也支持相同格式。

非 GLB 在浏览器本地转换为自包含 GLB 后上传，保留可转换的网格、材质、骨骼与动画。glTF 的 BIN/贴图、OBJ 的 MTL/贴图请一起选择或拖入，也可拖入整个模型文件夹（最多 128 文件、256 MiB）。缺少依赖会报错，不会从模型指定的网络地址下载。FBX 的程序材质、约束、复杂着色器可能无法完整转换；建议先在建模软件烘焙。STL 不包含贴图和动画；PLY 暂不支持纯点云。BLEND/MAX/MA/MB/USD 等源工程请先导出为上述格式。

连接模型到 **游戏开发、3D 模型生成、3D 动画** 时使用真实 GLB。连接图像/视频生成、ComfyUI、RunningHub、MiniMax、LLM 或 AI 游戏策划时，先调整预览视角并点击 **“设为参考视图”**，再从模型节点输出端连线，下游读取已保存的 PNG 参考图。改变视角后点击“更新参考视图”才更新下游；替换模型后旧参考图失效，需要重新保存。图像模型接收的是视图，不直接解析 3D 二进制。试玩中的点击、碰撞等交互由游戏开发节点生成的代码实现。

| 节点 | 功能与连线 |
| --- | --- |
| 模型资产 | 导入/替换 GLB、选择项目模型、填写用途、启用/停用、下载；输出到模型生成、动画或游戏开发 |
| 3D 模型生成 | 图片、多视角或文字生成模型；已有模型重新贴图、重建网格；接收图片、提示词、文档及源模型 |
| 3D 动画 | 接收模型，读取服务动作库、按名称/分类搜索、多选动作、绑定骨骼并生成动画；输出到游戏开发 |

预览支持旋转、缩放、平移、自动旋转、视角重置、线框/白模/材质、动画切换与暂停、全屏。画布重绘保留当前预览。生成结果可先预览再采用；只有采用后成为项目运行资产。运行资源仍由项目“启用”状态控制，并非仅按连线筛选。

图片、分组、生成器及输出节点可以连接模型生成节点，在“参数与输入”中勾选具体参考图。服务动作库提供预览地址时，可打开动作视频预览。生成成功后，“采用生成结果”直接成为卡片主按钮。

## 服务配置

生成节点的齿轮打开 3D 服务配置。支持 Meshy、Tripo、Hyper3D / Rodin 官方协议以及对应协议的兼容地址，可查询余额、启用/停用连接、添加自定义模型版本、修改默认面数等能力参数。官方版本能力按复用的 ohmygame 目录锁定；更改官方名称与默认面数不改变能力范围。自定义请求头不得覆盖认证字段。

3D 服务需要独立的 Key；OpenAI 兼容聊天 API 不能代替这些协议。密钥按登录用户存于本机私有数据目录，接口返回时隐藏 Key，不写入画布、项目源码包或模型下载请求头。运行需 Node.js 20+；预览引擎已离线打包。

Meshy 支持四种模型操作和动画；Tripo 同样支持四种操作，并可选择骨骼版本、角色类型与原地动画；Hyper3D 支持图片、文字、重新贴图，不支持网格重建和动画。面数、参考图数量、贴图模型等受所选服务版本约束，不满足时会明确失败。参考 WebP 会先转换为 PNG。动作最多选择 30 个；Meshy 按服务限制分批，最终合并到一个 GLB。

## 任务与交付

只有点击生成才提交任务，可能产生服务费用。任务有进度、阶段、错误、历史记录；取消停止本地等待，不能保证服务端取消或退款。“恢复原任务”使用原连接与冻结输入及付费提交凭据，不新建同阶段付费任务。连接/输入指纹不一致时拒绝恢复；提交结果不明确时阻止重复提交，应先到服务控制台核对。并发上限为每用户 2 项、实例 3 项。

模型单文件最大 100 MiB，图片/音频最大 32 MiB；当前项目运行素材总计最大 256 MiB。仅支持自包含、无需 Draco/Meshopt/KTX2 解码器的 GLB 2.0，与现有隔离试玩及导出运行时一致。模型二进制不会作为文本交给代码生成 AI；AI 读取资产 ID、用途、尺寸/网格及动画元信息，通过 GameAssets 加载。

采用后的模型进入试玩、源码/Web/正式包与项目备份。私有服务连接和付费任务日志不进入可移植备份；备份导入后继续使用已采用的 GLB。导出游戏请通过静态 HTTP 服务运行。

协议复用来源和重建说明见 `tools/model3d/NOTICE.md`。原创示例模型为 `docs/examples/model3d/robot.glb`，可用 `py -3.13 tools/model3d/create_demo.py` 重建。`tools/preview_game_pipeline.py --model3d --port 18774` 提供隔离离线模拟画布，仅用于验证功能，不代表真实服务的生成质量或计费行为。
