# 音频、项目文件和可玩场景节点

在游戏画布的添加菜单中创建节点。卡片只放预览、描述和主操作，连接、生成参数和场景源码在独立设置窗口中编辑。

## 音频

统一为「音频生成」节点，卡片内切换配音、音效、音乐、声音场景四种模式。旧音频节点保留原ID、连线、生成记录和对应默认模式，不再出现在创建菜单。切换模式后，旧结果仍可在任务记录中查看，已采用素材继续保留在项目中。协议适配器来自 ohmygame 原实现，见 `tools/audio/THIRD_PARTY.md`。语音可以选 Seed TTS 2.0 或 Seed Audio 1.0；其余三类使用 Seed Audio。音频服务 API Key 和完整接口地址在节点「设置 → 管理音频连接」配置，与聊天模型 API 独立。服务端需要 Node.js 20+；发布带上 worker.cjs，无须部署 node_modules。

输入描述，也可以连接策划、文档、文件或文本节点。合并描述上限2744字。可设置音色、风格、语速、音高、音量和目标时长；输出MP3/WAV/OGG，Seed TTS不支持WAV。音乐只支持纯音乐，不提供歌词、声道选择或保证无缝循环的假选项；声音场景可描述包含人声的复杂环境。

生成是项目私有持久任务；记录可回看，结果可试听，采用后成为媒体资产。可连开发/可玩场景节点，也可在「已采用资产」查看、下载或新建并连接场景。代码用 `GameAssets.createAudio(assetId)`；跨场景继续播放用 `GameScene.audio.play(assetId,{loop:true,volume:0.5})`，停止用 `GameScene.audio.stop(assetId)`。

提交时冻结输入并保存 requestId；网络错误后重试同一提交不会重复创建任务。已提交但结果不明确的任务禁止自动重发付费请求；取消只停止本地等待，不能保证服务端退费/终止。密钥仅在用户私有连接配置及进程stdin中使用，不出现在画布、公共任务或备份中。采用结果幂等，音频采用现有32MiB单项、项目媒体256MiB/200项限制。

## 文件资料

统一为「文件资料」节点，提供「导入文件」和「导入文件夹」两个入口，拖入文件夹同样创建此节点。旧文件/文件夹节点保持数据和连线兼容。支持选择或拖入文件，文件夹保留相对目录；可查看、逐项下载和ZIP下载。资料保存到项目私有资产树，不是任意磁盘目录的读写授权。单文件32MiB，项目文件256MiB/200项。拒绝路径穿越、重复路径、依赖缓存目录与 .env 凭据文件。

32KiB以内的UTF-8文本（TXT/MD/JSON/CSV/YAML/JS/TS/HTML/CSS/PY/GLSL）自动接入已有项目文档体系，连策划节点可引用，代码AI共享文本上下文总量最多32768字符。二进制原样保留下载，不声称能理解PDF/Office或任意二进制内容。项目文件作为开发资料随源码包和完整备份导出，不自动执行或当作运行时资源；图片、音频、3D运行素材继续走专用媒体节点。

## 可玩场景

每个节点有固定游戏窗口，首次出现自动准备预览，播放图标切换试玩，不拉伸卡片、不打开侧栏。设置中编辑名称、独立JavaScript、出口信号、初始共享状态；可连接开发节点并按工程清单顺序导入代码，再添加出口行为。多个场景之间画布连线定义跳转，循环可用；一个源场景的同一信号只能连一个目标。多个出口在源节点设置中给每条出线指定信号。「设为入口」设置整个场景图的启动场景。

API：`GameScene.state` 读共享状态；`GameScene.setState({score:1})` 更新；`GameScene.emit('next',{score:2})` 合并状态并从next出口跳转。状态JSON最多32KiB；最多50场景/200条出口边、单场景代码200000字符、全图代码1MiB。节点和连线变化自动保存，所有场景删除后清除活动场景图。

每个场景运行于不带allow-same-origin的独立sandbox iframe，跳转销毁旧文档，因此旧计时器、事件和普通场景音轨不残留。共享状态/信号消息校验来源、代数和容量。持续背景音乐由图运行时持有；停止试玩暂停音乐。独立场景图页面支持保存/载入当前场景和共享状态。卡片隐藏运行时导航，只保留游戏与播放开关。

工程构建固定整个场景图并沿用媒体资源打包，构建后编辑不会改写旧产物。源码包中每场景是独立 `game/scenes/<id>.js`，运行 `python build.py` 可离线重新打包。完整备份恢复包含原文件/目录和场景图；音频任务日志不进入备份。

## 验证

`tests/test_game_extra_nodes.py` 使用离线模拟服务走原始音频适配器，覆盖四种操作、采用/幂等、权限、模糊提交不重发、文件路径/ZIP/备份恢复、场景图与源码导出构建。`tests/test_game_extra_nodes.cjs` 覆盖画布连接、场景删除、出口路由、共享状态、来源隔离和停玩控制。隔离人工验收：`py -3.13 tools/preview_game_pipeline.py --port 18777 --extra-nodes`，访问终端输出入口，所有音频调用被强制替换为离线fixture；未验证真实付费音频渠道的听感/额度。

## 试玩与场景统一入口（2026-11-02）

新建菜单统一使用「试玩与场景」，在节点内通过「试玩来源」切换开发工程或场景与出口。开发工程保留固定版本试玩、自动化测试和失败反馈；场景模式保留场景源码、出口连线、入口设置、节点内试玩和运行错误。旧 gameScene/gameTest 身份兼容，不自动删除或合并已有卡片，避免多场景及测试记录丢失。切换来源可撤销，保留场景源码、图和连线；场景运行错误不等同于工程自动化测试结果。
