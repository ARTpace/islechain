# 画布图像生成节点

入口：刷新画布，在快捷菜单或右键菜单选择「图像生成」。

节点使用画布原生卡片，不嵌入文生图整页：提示词、参考图缩略图、模型、参数摘要与生成按钮直接显示，无图库与固定大留白。

模型和常用参数在画布顶层浮层中选择；提示词库、LoRA、参考图与高级参数在悬浮窗口中打开，不使用侧边栏，也不受节点边界和画布缩放裁切。提示词库和 LoRA 复用原有选择界面。提示词库的独立选择组件保留其已有 iframe 隔离，但不会把文生图页面嵌进节点。

每个节点独立保存提示词、参数、LoRA、参考图与提示词库选择状态。支持连线输入、从画布选图、拖入图片和本机上传，生成图片自动进入 Output 节点。旧版大卡片首次加载自动收紧，保留已有内容与输出。

独立文生图页和画布共用 `image-generation-workflow.js` 构建本地工作流；在线与本地生成复用已有后台任务队列。已提交任务编号随节点保存，刷新后继续等待；查询中断时可继续等待，避免重复提交。批次中一个任务失败仍收集其余已提交任务的结果。

本地服务不可达时，节点不会自动切换在线模型。原有 API、Modelscope、ComfyUI、RunningHub 节点保留；各旧节点特有的工作流能力尚未全部并入新节点。

验证：原生节点测试覆盖参数隔离、输入快照、结果输出、任务恢复、防重复提交、批次部分失败及提示词库消息来源校验。共享工作流测试覆盖仓库内文生图工作流，以及 Qwen / MOSS / FLUX.3 / Krea2 的参考图分支。旧图片编辑桥接测试通过。

隔离浏览器验证了模拟图片生成、原选择器悬浮显示、画布选图、LoRA 选用与刷新恢复。未调用真实付费模型，未验证真实模型生成或远端任务取消。停止等待不代表取消远端计算。

既有测试限制：test_canvas_input_links.cjs 的 loop 输入类型断言未包含此前加入的 gameIdea，与当前实现不一致，本次未修改。
