# Art Canvas 重构文档入口

> 状态更新：2026-10-22。当前处于 P2 首批路由迁移的集成修复阶段，尚未通过发布验收。

## 重要勘误

此前文档与会话将 P1、画布统一引擎和构建链描述为全部完成，这一结论缺少实际运行验证，不应作为上线依据。语法检查通过不等于应用可导入，独立 router 可加载不等于整体注册与共享状态正确。系统 Python 的完整 pip freeze 也不能直接视为项目可复现依赖锁。

现有文档中的接口清单是早期静态整理稿，不是完整 OpenAPI 合同；行号随迁移变化。涉及性能、覆盖率、体积、工期和质量评分的数字，除非附有可复现命令与结果，都属于待测目标或估算，不是测量结果。

Vue、React、Svelte 等框架仅为候选方案，尚未决定迁移。当前优先保持既有页面和 API 行为，不开展全面框架重写，不同时变更数据库格式。

## 当前执行规则

- 后端入口与 router 由同一负责人整合，避免并行删除入口代码。
- 独立审查迁移前后 HTTP 方法、路径、重复项和注册顺序；已有重复路由也必须先记录，不擅自删除。
- 修复前期画布抽取与 manifest 接入的回归；不能运行验证的新实现不得替换线上入口。
- 单元与冒烟测试使用临时目录及模拟上游，不操作真实用户、画布、生成任务或外部付费接口。
- 不自动提交、不重写 Git 历史、不自动重启正在运行的服务。
- 验收必须记录命令、退出码、通过与跳过项；缺少浏览器验证必须明确说明。

## 发布门槛

应用应能在隔离环境中导入，所有预期路由保持一致；认证、画布与代理接口具备正常及失败路径测试；关键页面脚本通过语法验证，浏览器核心交互经验证后才可宣称可发布。任何一项未通过，保留为未完成，不以减少代码行数替代正确性。

## 回退原则

首先备份现有未提交改动与私有数据。在独立副本验证回退，仅撤销本轮明确引入的问题；禁止用 git reset --hard 清空混有用户工作的目录。忽略规则不会删除 Git 历史里的凭据；凭据失效与历史重写需另行确认、评估协作者影响。
