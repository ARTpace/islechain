# 材质制作

更新后重启后端并刷新画布。添加「PBR 材质」，填写需求或连接参考图片。

## 单个材质

1. 在唯一的提示词模型下拉中选择已配置、已启用的聊天模型；有参考图时需支持视觉。渠道随模型保存，不单独显示平台选择，调用时由服务端检查认证配置。
2. 选择材质人设，点击「编写提示词」。提示词直接写入原生生图节点，不再新建文本节点。
3. 在颜色、法线生图节点分别选择图片模型或本地工作流，直接编辑提示词。两个节点可以使用不同模型；法线模型需支持图片输入。
4. 点击「生成贴图」。通用、写实、风格化人设依次执行颜色 → 最终颜色参考法线 → 六通道 PBR。快速人设只生成颜色，然后算法估算其余通道。

节点结构为颜色生图 → 法线生图，颜色和法线都直连材质节点。不会自动创建图片输出节点；用户已有的显式输出连线仍可接收结果。旧文本节点的数据保留，重新编写时仅断开旧提示词连线。

六张贴图横排，点击缩略图在当前页面放大。底部一行提供边差、色/法 2×2 平铺与偏移检查。边差是左右/上下边缘像素差，越小通常越容易拼接，不是自动验收结论；详细限制在提示图标中。

「设置」保留导入颜色的纯算法模式、输入图选择、尺寸、法线格式、粗糙度、金属度及 PBR 查询。纯算法模式不调用聊天或图片 AI。Designer 导入和材质球仍为独立可选操作。

## 人设与技能

预设位于 packs/material-skills/<id>/，每项由 preset.json 与 SKILL.md 配对。元数据包括 name、description、persona 与 workflow；工作流支持 color-normal、color-only。新增同样目录结构即可加入人设，下次刷新画布加载。文件是提示词与受控流程配置，不执行任意技能代码。

内置通用、写实、风格化、快速四个人设。公共输出协议负责校验 AI 返回格式，各自的人设和技能决定材质取舍及提示词；工作流由预设配置决定。

## 批量

展开「批量制作」，每行填写一个需求，单批 1–20 项。「准备批量」创建各项独立的材质/生图节点，并逐项编写提示词，不生成图片。复用当前人设、提示词模型和已有颜色/法线节点各自的生图配置；没有生图配置时使用原生节点默认值，生成前可逐项调整。

「生成 / 继续批量」串行生成，每项 PBR 完成后才进入下一项，结果保留在各项材质节点。可请求当前项完成后暂停。错误或刷新后需主动继续；已完成项跳过，状态不明且没有任务编号的图片请求不会自动重发。当前页串行运行，不是关闭浏览器仍执行的后台队列。「新建批次」保留已有节点和结果，只清除批次跟踪。

## 恢复与限制

流程与任务 ID 随画布保存；「继续流程」只查询已接受的任务。需求、参考、人设改变后需重新编写；提示词在执行中改变会停止后续阶段。颜色更换后需要对应的新法线。旧结果在输入变化后停止向下游传递。

PBR 计算需要 Pillow、NumPy。高度、AO、粗糙度为估算，金属度为指定基线；快速模式会把色差或阴影误判为几何。AI 法线可能重画细节，不能保证无缝和准确对齐，也不自动修补接缝。

Designer 导入需要本机 127.0.0.1:9765 网关及唯一可识别的 Designer 实例。导入未知时不会重发。工程链接当前账号画布 materials/<任务ID>/ 中的贴图，移动时保留整个任务目录。
