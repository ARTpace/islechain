# 代码开发能力对齐 OhMyGame

更新：2026-11-03。范围为游戏代码开发；保留 FastAPI、原生前端和现有项目版本体系，不迁移到 Electron/React。

## 已实现

- 后台持久开发任务：关闭页面继续执行，支持暂停、取消、显式恢复、幂等和项目文件锁；重启标记中断，不自动重放模型调用。
- 候选工具支持跨文件修改、素材检查、行为回归及自由 Chromium 试玩；真实截图经 hash/epoch 校验后进入下一轮模型上下文。源码变化使旧试玩失效。
- 标准 Web 工程：Vite/TypeScript 模板、UTF-8 源码 ZIP 导入、npm 安装/构建、开发服务和生产预览。
- 本机执行按项目显式开启：独立工程副本、argv 启动、有界日志、超时与所属进程树清理；执行副本不是 OS 安全沙箱。
- Codex CLI JSONL 适配：新会话、指定所属会话继续、取消和事件记录；必须收到 turn.completed 才判定成功，不仅看退出码。
- 外部修改先看差异再采用；采用受版本/hash/epoch 和保护快照约束。构建产物冻结校验后导出。
- 已选图片、音频和模型写入工程 public 素材目录；生成素材清单和 ART_CANVAS_CONTEXT.json 策划上下文。源码导出携带选用素材。
- 可移植备份不携带本机执行授权、执行副本或运行记录。

## 使用入口与架构

游戏开发节点 →「打开游戏工作台」。首页为开发需求与运行试玩，常用导航为开发 / 试玩 / 源码；数值、测试、交付和项目管理在「更多」。本机授权、标准模板与匹配会话按需引导准备，常用流程不再要求手动选择会话。低频模型、命令与记录在「高级工具与运行记录」；外部改动仍先审阅再保存。

核心模块：

| 模块 | 职责 |
|---|---|
| core/game_development_tasks.py | 宿主模型后台任务、事件与项目锁 |
| core/game_candidate_runtime.py | 候选运行、真实截图与自由试玩 |
| core/game_native_runtime.py | 标准工程副本、npm/Codex 运行、差异采用及导出 |
| core/game_process_tree.py | Windows JobObject 与 POSIX 进程组清理 |
| routers/game_native_runtime.py | owner、loopback、同源和显式请求头校验 |
| static/js/game-native-runtime.js | 工作台执行、日志、会话与采用入口 |

原有受控候选链路与本机工程链路并存。开发服务单独持锁，允许同会话修改/构建；代码写任务保持单项目排他。任务最长30分钟，宿主开发任务默认16步、开发节点32步、上限96步；连续失败三次停止。

## 限制

本机模式使用当前用户权限；环境过滤和独立目录不提供隔离。沿用 CLI 自身登录，不复制凭据、不启用绕过权限参数。npm 安装禁用安装生命周期脚本，但显式 build/dev 仍执行工程代码。

源码 ZIP 导入限定50个 UTF-8 文件、40MiB，要求根 package.json；不宣称任意二进制工程无损导入。二进制素材使用素材节点或完整项目备份。执行源码扫描最多500文件、单文件1MiB。执行会话最多20个，不自动删历史。

跨 worker 停止请求只能由启动进程处理，其他 worker 返回409；当前适合单服务部署。Windows 进程树已实测；POSIX 崩溃后的清理尚未实测。

## 素材接入简化（2026-11-03）

画布选中素材后点击“用选中素材做游戏”；也可在工作台添加文件、导入或拖入文件夹。接入后默认供 AI 使用，无需逐项填用途、路径或资产清单。相同内容自动复用；同一画布来源更新保留素材 ID。文件夹重导支持内容去重，但不承诺修改后的文件自动保持原 ID。素材和上下文随下一次开发提供给 AI，不额外调用模型分类。

## Agent、对话、恢复与本机插件（2026-11-03）

- 开发需求旁选择 Codex / Claude Code / OpenCode；默认自动发现，可在高级工具设置实际可执行文件。Claude 支持本机 native npm 布局与旧 Node 入口；不执行 cmd/ps1/bat 包装脚本，不添加绕过权限参数。登录沿用 CLI 自身配置。
- 每轮保留需求、Agent、模型、回复、状态与关联运行记录。切换 Agent 或工程更新时从当前分支交接最近12轮（最多24000字符），不额外调用模型总结。宿主工程任务摘要与本机对话双向进入上下文；原生会话仅续接相同 Agent 的有效成功上下文。
- 每轮执行前冻结源码；可从该轮开始前分支，或撤销保存源码并创建恢复分支。旧对话和工程副本保留。快照 hash、项目版本、运行互斥与恢复容量均有保护；素材、策划及外部引擎工程不随源码撤销。
- 内置 Godot、Unity、Unreal、Cocos Creator、Blender、Aseprite、Tiled 命令适配。用户按项目启用并绑定实际工程后，可选择开发目标，直接开发或运行该工程，不强制创建Web模板。高级工具可运行固定操作，Agent 上下文提供实际 argv。操作支持范围随工具而异，包括编辑器、检查、运行、Web构建、渲染或素材导出；不代表各引擎所有能力均已集成。
- 插件复用现有本机执行器、超时、进程树停止和日志。输出在项目 native-plugin-output 下。绑定配置、运行和对话快照不随可移植备份恢复授权。
