# 对话视频

对话页输入栏直接选择「图片 / 视频」。视频模式下直接选择视频模型、秒数、比例和分辨率；选择即生效。明确说“生成一段视频”“让这只猫动起来”时也会识别视频任务。

- 文生视频：`生成一段 8 秒竖版视频，一只小猫在草地上跑步`。
- 图生视频：先添加参考图，或生成图片后发送 `让刚才这只猫动起来`；自动引用上一张生成图。
- 视频结果在聊天内播放、下载，并保存在原对话和生成历史中。
- 点击「停止」停止当前等待；已经提交的远端任务可能继续执行，完成后写回对话，重新打开可查看。不会自动重新提交付费任务。
- 失败时可按原参数重试；重试会创建新的生成请求。

模型来自 API 设置中已启用且已配置的视频平台，不把图片模型当视频模型使用。图片与视频的参数相互独立。

## 实现

- `static/modules/chat-video.js`：类型/模型/参数控件、视频意图、`VIDEO {"prompt":"…","params":{…}}` 解析、任务等待、播放卡片。
- `GET /api/chat-video/models`：安全的视频模型目录，不返回 Key。
- `POST /api/chat-video/tasks`：创建账号隔离的后台视频任务。
- `GET /api/chat-video/tasks/{task_id}`：按所属账号查询状态。
- `routers/online_gen.py`：复用画布视频路由和统一结果保存；修正原路由丢失真实平台配置、即梦请求对象的问题。
- `core/video_generation.py`：OpenAI Videos 兼容适配；仅提交一次，后续轮询不重新生成。

OpenAI 协议采用 `POST /v1/videos` multipart（model、prompt、seconds、size、可选 input_reference），查询 `/v1/videos/{id}`，完成后下载 `/content` 或接收返回的视频 URL。一次最多一张参考图。即梦复用现有 CLI，保留首尾帧/多图参数。其他旧视频协议暂仅接通原有文生视频，未接图生视频时明确提示。

通用参数校验范围为 1–60 秒、列出的比例、Auto/480p/720p/1080p；并不代表每个模型都支持所有组合，上游不支持时显示错误，不擅自替换参数。

运行中的后端需要重启一次以加载新增路由。验证包含本地模拟提交、轮询、视频文件、账号权限和持久化，未进行付费生成。当前配置 `agnes-video-2.5-flash` 已能被目录发现；免费空请求预检确认 `/v1/videos` 到达“缺少 model”的校验，未提交模型或提示词。真实视频质量、时长组合与服务端实际兼容情况仍需实际生成验证。
