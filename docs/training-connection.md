# 独立训练器接入

art-canvas 通过本机 MCP 连接 Kohya-LoRA Tool，不在自身 Python 环境安装训练依赖。

## 首次连接

1. 运行 `H:\AI-Tools\Kohya-LoRA-Tool\Kohya一键工具.exe`。
2. 在训练器「外部 Agent · MCP」开启本机接口。仅查看时保留只读；需要创建项目、保存参数、下载或训练时，手动开启操作权限。
3. 复制「通用配置」或「Codex 配置」。进入 art-canvas 侧栏「模型训练」，粘贴后点「保存并连接」。

默认地址 `http://127.0.0.1:19366/mcp`。支持更改端口；不支持远程地址。连接密钥在当前系统用户的 art-canvas 数据目录保存，GET 接口只返回是否已配置，不返回密钥。不要把配置发到聊天或公开仓库。

## 已接入

- 环境、显卡、训练引擎和权限状态。
- 读取实际项目及模板、新建项目、常用参数与高级配置编辑；提交实际 revision，仅保存修改字段，旧配置由训练器备份。
- 素材检查、训练预检、预处理/打标、开始训练、从完整快照续训、检查后继续、请求停止。
- 增量日志与真实任务进度、当前任务恢复、训练历史、采样文件清单、诊断。
- 按当前项目调用训练器的环境安装与指定模型组件下载；需要用户点击确认，不自动下载安装。

训练预处理后可能进入 `awaiting_review`，表示训练引擎还未开始。请在训练器检查实际图片及标签，在 art-canvas 检查任务素材并勾选确认后继续。请求停止后仍需查看最终状态；关闭页面不停止训练。

## 当前边界

- 训练器必须保持运行；未开启 MCP 或缺少连接密钥时，art-canvas 不会绕过权限连接。
- 续训、量化和模型支持取决于所选引擎及训练器版本，连接成功不等于训练环境已就绪。
- 超时后不自动重发修改/启动请求。请先检测连接、查询任务，确认状态后再操作。
- 素材通过当前项目的本地目录配置；当前版本没有把资产图库自动复制进训练集。
- MCP 目前返回采样文件元信息，此版本展示文件清单，不提供采样图 A/B 对比和自动导入 ComfyUI LoRA 库。
- 不会自动关闭 ComfyUI 或卸载其模型。训练前自行结束生图任务、按需释放显存。
