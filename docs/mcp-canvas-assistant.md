# MCP 工具与画布 AI 助手

画布顶部「AI 对话」打开右侧聊天栏，右上角齿轮打开独立的「MCP 工具设置」，不在节点卡片中增加配置面板。

当前实现为 MCP 客户端与工具调用助手，不提供供其他 AI 客户端直接连接的画布 MCP 服务端。

## 接入工具

在「MCP 工具设置」添加服务，支持通用 `mcpServers` JSON 或单个配置对象：

```json
{"mcpServers":{"art-tools":{"url":"http://127.0.0.1:3000/mcp","headers":{"Authorization":"Bearer YOUR_TOKEN"}}}}
```

本地程序示例（请使用真实存在且信任的可执行程序）：

```json
{"mcpServers":{"local-art":{"command":"python","args":["C:/tools/art_server.py"],"cwd":"C:/tools"}}}
```

- 传输支持 `http`（Streamable HTTP）、`sse`、`stdio`。使用官方 Python MCP SDK，依赖在 `requirements.txt`。
- stdio 的命令和参数分开，不经过 shell；保存配置不会启动，连接、发现和任务调用时会启动，任务结束由 SDK 关闭。
- 展开服务，点「连接 / 查看工具」，勾选允许 AI 调用的工具。默认没有工具授权；工具名称改变后需要重新授权。
- 每个工具显示风险等级：只读（`readOnlyHint` 为真）、写入（`destructiveHint` 为假）、危险（其余，含服务未提供注解的情况）。风险按服务声明判定，服务不声明注解时按最危险处理。
- 「信任此服务」勾选后，该服务的工具在执行前不再逐次确认。仅对自己信任的本机服务使用。
- 密钥放入 `headers` 或 `env`，不要放在 URL、command 或 args 中。读取配置不返回 headers/env 值；编辑时省略这两个字段保留旧值，显式 `{}` 清除。
- 配置保存于当前系统用户数据目录的 `mcp-servers.json`，属于本机配置文件，不是加密保险库。
- MCP 管理、执行及含 MCP 的开发步骤仅允许主机本地登录会话使用；不开放给局域网访客。支持远程 HTTP 服务地址，但不实现 OAuth 登录，需使用服务提供的请求头认证。
- 服务之间的连接会被复用，空闲约 5 分钟后释放；配置变更后自动重建连接。

## AI 工作流

侧栏中间显示连续对话，底部固定输入框、模型选择、工具选择与发送/停止按钮。桌面打开时画布让出侧栏空间，拖动分界或聚焦分界后按左右键可调宽；窄屏覆盖显示，可收起回到画布。收起不会中断正在进行的任务，停止需点击停止按钮。

选择已有聊天模型，描述目标，可选本次使用的 MCP 服务。Enter 发送，Shift + Enter 换行，中文输入法选词回车不会发送。模型必须支持 OpenAI 兼容的 `tools/tool_calls`；渠道不支持时会报告错误，不模拟调用成功。

选中画布节点，再点「引用选中节点」，引用以可移除标签展示，模型使用真实节点 ID 定位。每轮使用最新画布和最近 12 条对话文本；过去方案的采用/失效状态会进入上下文，模型必须读取当前画布后再编辑，不重复执行历史工具调用。

## 工具确认、进度与资源

危险或写入级工具在执行前会弹出确认卡片，显示工具名、风险等级和参数。可选择「允许一次」「本次会话允许」或「拒绝」；拒绝会把失败原因交回模型，不会执行外部操作。「本次会话允许」只对当前画布对话生效。

工具执行期间的进度通知会实时显示在执行记录中。

服务提供的资源与提示词可在「MCP 工具设置」中查看并勾选，勾选项会作为上下文附加到本次请求。资源文本截断到 8000 字符。

工具返回的图片会作为图像附加到模型上下文（单张长边压到 1024，最多 4 张），二进制本身不进入文本上下文。渠道不支持图像输入时自动改用文本重试一次；此行为可能丢失工具产生的图像语义。

助手可读取当前画布，调用已授权工具，并提交工作流候选。支持新增文本、LLM、图片、图片生成、输出及主要游戏节点，修改允许的文本字段、添加连线。游戏节点要求已有当前画布的游戏工程。

消息、未发送草稿、模型和 MCP 服务选择按画布保存在当前浏览器，最多保留 40 条消息，不跨浏览器同步。不保存 MCP 凭据、工具原始结果或可执行候选。刷新后的未采用方案标为失效；刷新时中断的回复标为已停止。存储不可用时提示用户，当前对话仍可继续。渠道失败和手动停止会保留输入供修改重发。

界面显示 AI 处理轮次、工具名称和调用状态；支持停止。一次任务最多 8 个 MCP 服务、8 轮工具执行，每轮最多 8 次调用；工作流最多新增/修改各 24 个节点和 64 条连线。工具结果会限制长度，二进制媒体不会塞入模型上下文。外部文件路径不会自动变成画布资产，需继续使用现有导入流程。

## 游戏代码开发

服务勾选「游戏代码开发也可使用已授权工具」后，主机画布中后续新建的多文件规划/维护候选记录服务 ID，后续步骤使用同一组服务。已有候选不自动扩权。取消授权或停用服务后，旧候选会停止 MCP 执行，需重新建立候选。

代码修改仍进入原有候选、构建和回归流程。MCP 工具可能自行操作外部文件，它们的副作用不会被工程候选撤销；不要授权访问无关文件的工具。调用失败、超时和取消都不会自动重放工具操作。

## 验证

`tests/test_mcp_tools.py` 覆盖真实 stdio/HTTP SDK 握手、工具发现与调用、授权过滤、模型工具循环、多轮历史、工作流校验和本机访问限制。`tests/test_canvas_agent_state.cjs` 覆盖消息与草稿恢复、画布隔离、旧候选失效、历史长度和存储失败。`tools/preview_game_pipeline.py --port 18777 --mcp` 使用临时数据、离线模拟模型与真实本机测试 MCP 服务，供浏览器验收，不消耗真实模型额度。

## MCP 可靠性迭代（2026-11-04）

- 工具兼容性在执行前通过 SDK 方法签名判断。删除“捕获 TypeError 后重新调用”的逻辑；外部执行失败或取消时标记连接失效，提示操作可能已经完成，不自动重放。下一次新请求重建连接。
- MCP isError 保留有长度上限的文本错误详情，隐藏已配置 headers/env 值及常见令牌。画布 AI 与手工调用入口共用单次执行路径；业务失败不再只显示无原因的失败。
- 最多 8 个服务并行发现；单个服务连接或发现失败单独进入 UI 和返回 trace，其他服务以及内置画布工具继续可用。一次准备仍需等待发现操作结束，未引入后台热插拔。
- 资源、资源模板、提示词列表支持分页，最多 8 页、128 项，重复游标报错；根据服务声明跳过未支持能力。连接失败明确报错，不伪装为空列表。
- 连接持有任务主动检查空闲状态并关闭传输，不必等待下一次请求触发清理；取消等待连接时释放引用。
- Windows 复用 node_credentials 的当前系统用户 DPAPI 存储 headers/env；旧明文配置首次读取自动迁移，省略凭据仍保留，显式空对象清除。非 Windows 不降级为明文保存，仍需后续实现对应平台安全存储。
- SDK 将 stderr 文件描述符直接传给子进程，无法用普通 Python 文本包装器脱敏，因此停止持久化新的原始子进程 stderr，以免记录显式配置的密钥。已有历史日志未删除；结构化错误仍在任务 trace 展示。脱敏不是任意变形敏感信息的检测器。

验证：tests/test_mcp_tools.py 完整执行 31 passed、8 subtests passed；最后补充主动空闲回收、资源/模板分页两项后，连同本地路由检查 3 passed。包含真实 SDK stdio/HTTP 握手与调用、写入后 TypeError 不重复执行、服务故障隔离、真实连接重建、旧配置迁移和错误脱敏。没有调用用户付费模型或更改实际作品。未重建安装包。

本轮交付以上基础可靠性改进。按任务动态裁剪内置工具、可恢复的持久任务状态、工具级权限覆盖仍是后续迭代项，不应将当前实现称为已支持这些能力。
