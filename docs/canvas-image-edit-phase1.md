# 图片编辑画布：第一期

## 统一创作控制台与进度卡（最新实现）

画布输入框现通过同源嵌入模式直接复用 `static/app/zimage.html` 的 `generationComposer`，不再单独实现简化的服务商/模型输入栏。模型切换、本地/在线引擎、比例、质量或步数、分辨率、张数、随机方案、参考图上传、资产选择、提示词及高级参数继续使用原页面的控件、状态和提交逻辑；具体显示项仍由原页面按模型能力决定。

嵌入模式只隐藏画廊等页面外壳。父子页面限定同源和精确窗口来源，通过请求编号隔离进度和结果。生成期间锁定当前编辑目标，切换选中图片不会把正在生成的结果写到另一张图片上；生成完成后再同步新选择。原有页面的独立使用不受嵌入模式影响。

生成期间自动展开该图片的历史，直接使用 `CardProgress.attach/update` 显示排队、采样与在线任务状态，完成后替换为历史版本；失败清除进度卡并显示错误。卡片刷新前销毁进度实例，避免遗留计时器。生成仍按原页面保存其历史。刷新整个画布会中断前端的嵌入任务跟踪，未确认的结果需到文生图生成历史查看，不声称刷新后自动恢复。

验证：嵌入页面浏览器加载与控件检查；父子消息来源和请求隔离、重复结果去重、版本保留、失败清理测试；相关 JS 和两页内联脚本语法检查。未提交真实模型生成，未逐一验证所有模型参数组合。

## 图片版本历史（最新行为）

对话编辑生成的结果现收进原图片节点的 `imageVersions`，不再为每次对话生成新建旁边的节点。右上角数字包含编辑前原图和生成版本；点击展开后卡片纵向显示历史，最新结果在前。新结果不自动覆盖当前图片，点击版本后替换当前显示内容，原图始终可选回，切换可撤销。数据与画布一起保存，展开状态仅保留在当前页面。抠图仍新增独立图片节点并保留来源线。

版本恢复同步图片地址、名称和修改描述，并清除旧尺寸缓存，避免不同尺寸图片切换后沿用错误比例。重复查询同一任务不会重复添加相同结果。当前尚未验证真实 API 出图与页面视觉效果；以下早期章节中“智能改图新增节点”的描述已由本节取代。

## 选中图片的编辑入口

单选图片时显示紧凑的图标文字工具条：智能改图、抠图、裁剪、绘制、预览、下载。画布底部同步显示可收起的编辑输入框，包含当前参考图、修改描述、服务商和模型选择；取消选择或多选时隐藏。描述草稿随原图节点保存。

「智能改图」聚焦编辑框。提交使用现有图片任务 API，发送当前图片作为参考图，默认原图比例、一次一张；实际支持能力和费用取决于配置的模型。结果新增为普通图片节点并展示来源连线，原图保留。任务编号随画布保存，刷新后重新选择原图并提交可查询已有任务，避免重复生成。自动恢复、真实 API 出图和页面视觉效果尚未实测。

## 第二期：画布内蒙版抠图

单图工具条的「抠图」已改为专注选区编辑：深色背景、原图上的蓝色棋盘格选区、底部工具条。进入后自动识别主体，支持画笔补选、橡皮擦、矩形补选、笔刷大小、滚轮缩放、选区撤销/重做。模型设置折叠到辅助面板，SAM3 可指定保留主体。没有选区时禁止生成。

自动识别从现有透明 PNG 提取 alpha，不会立即插入结果。点击「生成」后将用户修改后的蒙版与原图合成透明 PNG，上传并新增图片节点。复用原有画布、抠图接口和图片上传接口，无新增后端依赖。生成保存期间暂时禁止退出，避免取消后仍插入图片。

边界：当前矩形框选是手动补选，不是即梦的智能区域快选。蒙版编辑最长边限制为 2048 像素，最终 PNG 保留原图尺寸，极细边缘可能受蒙版分辨率影响；超过 3200 万像素的图片需先缩小。选区历史按 64MB 预算保留最多 20 步。退出不保存未生成选区；自动识别不可用时仍可手动画选区。当前尚未完成登录后的真实模型和浏览器视觉联调，不能声称与即梦完全一致。

新增检查：`node tests/test_canvas_mask_editor.cjs` 覆盖软 alpha 选区历史、撤销/重做分支和内存上限。

图库与对话图片缩略图上的剪刀入口改为「编辑图片」，在新标签页创建独立的普通无限画布。使用实际点击的图片，先保存原图节点再进入画布；不导入或覆盖另一个正在使用的画布。

选中单张图片时显示抠图、裁剪、绘制工具。裁剪和绘制复用原有图片编辑器，仍沿用其修改当前图片的行为。

抠图面板读取后端可用模型，提供自动选择、指定模型、SAM3 主体描述、重新生成和任务进度。调用现有 `/api/image-cutout`，图库历史抠图界面和画布共用同一个客户端。

抠图结果新增为普通图片节点，保留原图，记录来源图片、模型和任务信息，不添加工作流执行连线。同一来源的相同结果不会重复插入；不同结果纵向排列，新增结果可通过画布撤销移除，并沿用画布自动保存。结果可以再次抠图或使用原有图片编辑器。

## 当前边界

- 每次从缩略图进入都会创建一张独立画布；暂不提供合并到已打开画布的选择。
- 关闭抠图面板不会取消任务。刷新整个页面会停止客户端轮询；再次提交相同图片与参数可查询后端缓存任务。
- 任务运行期间切换到另一张画布，不会把结果插入错误画布；回到原画布再次提交可查询结果。
- 尚未新增去水印、AI 修复、遮罩重绘和统一非破坏性编辑历史。这些功能需要继续接入对应后端与蒙版交互。

- `node tests/test_card_cutout.cjs`：共享抠图客户端、进度、换模、版本、对比及失败处理。
- JavaScript 语法检查通过。当前 Python 缺少 pytest，未运行静态页面 pytest 检查。
- 本地浏览器未登录 ArtCanvas，完整页面交互与真实 ComfyUI 模型出图尚未验证。即梦的登录状态不等于本地工具的登录状态。
