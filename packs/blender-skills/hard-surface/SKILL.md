# 硬表面道具师 · PBR 作业手册

按参考制作硬表面道具，先校准结构与曲率，再完成 UV、必要烘焙和可导出的 PBR 贴图。

## 节点执行约定

- 本手册是 hard-surface-pbr-skill 的基础适配版，内容自包含，不依赖外部 references 文件。
- ponytail: 复用节点的一键执行、灰模开关和检查点；不加入四阶段人工停等、Substance 或生图依赖。
- 用户需求、目标面数、灰模范围与场景保护规则优先；本手册补充通用建模流程的材质与验收步骤，不强制写实磨损，不限制材质槽数量。
- 仅使用当前开放的 Blender 工具。不调用 shell、联网、Substance 或图像生成，不安装插件。不要声称已生成 SPP/SBS 工程。
- 只操作本次获准的对象；新建内容放 ai_build。改造任务先保留原有 UV、材质和用户手改，不为局部修正重建全件。
- 最终 GLB 路径为 `{out_path}`。额外文件只写其父目录；沿用节点指定的 checkpoints 路径，不另建一套版本系统。

## 1. 结构分析与灰模

- 先简述部件、比例、截面、厚度、连接和材料；参考没有显示的背面与尺寸标为推断。无参考时以需求为准，不虚构已完成原图对照。
- 区分平面壳体、旋转体、弯管和连续曲面：分别选择截面挤出、旋转、曲线或低密度控制网格。基本体可以起形，不能以堆方块替代曲率、开口和装配关系。
- 先解决最难的完整局部，再扩展其余部件。倒角宽度按实际尺度决定，不用倒角掩盖错误主轮廓；圆弧分段服从剪影和面数预算。
- 用 look 查看接近参考的视角和第二方向，检查长宽比、圆弧、缝隙、穿插和漏件；发现明显差异先修正，再继续。
- 导出节点要求的灰模检查点。若启用“先做灰模”，到此完成自检并导出最终灰模，跳过下列材质与烘焙。

## 2. 塑形与可编辑源

- 主轮廓、厚度、孔口、支撑和装配优先于螺丝、刻字和磨损。重复件可用 ARRAY，曲面对称可用 MIRROR，控制笼配合 SUBSURF；按部件选方法，不强迫全部使用同一种技术。
- 合理布线，避免曲面细长三角面、叠面及布尔后的反光夹痕。应用修改器前检查比例与法线；不要使用已删除的 mesh.use_auto_smooth API。
- 只有法线烘焙确有收益才制作对应高模；不要默认复制整件增加任务开销。低模必须保留剪影、主曲率和厚度，不能指望法线贴图补救形状。
- 只导出本次资产，避免源控制网格、高模和渲染辅助物重复进入 GLB。按节点路径保存结构检查点。

## 3. UV、烘焙与 PBR

- 有图像纹理的网格必须有有效 UV。优先保留有效的原 UV；新展开按硬边、隐藏面和材料分界选择接缝，排布后查看明显拉伸、意外重叠、密度差与岛间留边。不虚报覆盖率。
- 优先利用用户提供且可读的贴图。BaseColor 按 sRGB 解释，Normal/Roughness/Metallic/AO 使用 Non-Color；法线通过 Normal Map 节点进入 Principled BSDF，默认采用 glTF 的 OpenGL 切线空间约定。
- 无贴图时先匹配大块基础色、金属度与粗糙度，再按需求添加木纹、制造痕迹或旧化。程序纹理需要实际烘成图像后才能作为 GLB 贴图交付；不得把 Blender 节点显示正常当成导出成功。
- 烘焙在当前资产的隔离副本/临时场景中完成，不能更改用户原场景的渲染设置。使用 Cycles，目标网格要有 UV，每个参与材质需有活动 Image Texture 作为烘焙目标；设置合理留边，结束后恢复临时状态并清理本次临时对象。
- 需要高低模传递时，核对对象选择、活动低模、射线距离/笼体，烘焙切线空间 Normal 与需要的 AO；查看贴图和模型上的接缝、漏烘、黑斑及方向。没有高模时不伪造“高模法线”，不制造空白贴图充数。
- 程序 BaseColor 可经临时 Emission 烘焙 EMIT，避免把灯光混入颜色；粗糙度/金属度按各自标量烘焙，结束后恢复节点连接。失败时保留已验证的简单 Principled 材质，并在运行记录中明确缺失项，不反复全件重烘。
- 使用 glTF 支持的 Principled + Image Texture 连接。不要依赖导出器自动烘焙程序节点。普通非发光物体保持发光为零，避免颜色被洗白。
- 导出前检查图像已保存或打包且实际绑定，GLB 中嵌入贴图。AO 若未按导出器支持的方式绑定，只作为辅助贴图保存，不宣称已嵌入；Height 默认不作为标准 glTF 材质通道。
- 材质完成后保存节点指定的材质检查点。

## 4. 导出回读与交付

- 先保存可编辑源到最终 GLB 同目录的 source.blend，保留控制网格与材质来源；GLB 只选本次交付对象。不要覆盖用户原工程。
- 按节点约定导出最终 GLB，打印实际三角面数、尺寸、材质数和使用的图像；目标面数按节点硬约束执行。
- 将最终 GLB 回读到隔离的临时场景，检查对象、尺寸、贴图绑定与正常着色，用 look 查看接近参考的视角及第二方向。若工具无法查看隔离场景，如实记录未完成的视觉回读，不修改用户场景来强行检查。
- 回读后恢复工作场景，清理本次临时数据。原模型与回读模型不能同时留在最终导出集合里。
- 运行记录简述实际完成项、推断、降级和未解决差异；不能用文件存在或导出成功代替造型与材质验收。
